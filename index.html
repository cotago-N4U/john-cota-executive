Graphic Design Workflow

One place to request work, with rules for who could change the scope, clear an estimate or release files to print.

Podio is a work management platform with configurable forms and workflows. Creative Services used it as the front door for design requests.

Follow a request

See where a routine request changes course.

  1. Request in Podio ↩ New request
  2. Assign and log ↗ Estimate check
  3. Review drafts ↻ Revision loop
  4. Release to printer
  5. Close project

Standard request

Give the work an owner and a record.
Intake and assignment
For new work, the diagram recommends consulting John before submission. John contacts the requester to clarify details or suggest changes when needed. He assigns the designer and updates the design log.
Design review
The specialist supplies assets and works directly with the designer. The specialist or project manager reviews the draft. John provides design direction and overall design approval.
Print handoff
Design waits for print instructions, uploads files to the designated printer, then sends the production manager and specialist a PDF sample and file link before closing the project.

External designer

Review the estimate before design begins.
Who decides
John requests and verifies the vendor’s estimate, then approves it or asks for an adjustment.
What gets recorded
John shares the project log with the vendor and records the estimate in the log.
Where it rejoins
The designer contacts the project specialist if the specialist has not reached out. This is where the external and internal routes rejoin.

Draft needs revisions

Keep review, language routing and release distinct.
What loops
The designer sends second, third and final drafts as needed. A draft can be approved at any of those review points.
Where language work goes
The diagram shows layouts for threshold languages on the revision path. It directs that draft to the team labeled C&L.
When print starts
John provides overall design approval. After approval, Design waits for print instructions before preparing files for the vendor.

Specs change midstream

Open a new request when the specifications change.
New specifications
The requester submits a new graphic design request in Podio.
Content change
John checks whether the change fits the existing specs. If an adjustment is possible, he works with the production manager and specialist to verify it.
Rush request
John checks whether the requested date is achievable. He adjusts it or proposes alternatives.
Who handles questions and service issues?
Assigned designer
Questions that leave the project specifications intact.
John Cota
Project changes, concepts, general questions and service concerns, including prepress or technical issues.

Agentic AI / John Cota

How I work
with AI agents.

I use Claude and other AI tools across the work I already do, from shaping a brand brief to testing a website or preparing a video treatment.

When a task has several steps, I give the agent an objective, the sources it can use and a point where I need to make a decision. I review the evidence and approve what moves forward.

  1. 01 / BriefSet the goal and boundaries
  2. 02 / BuildGive the agent sources and tools
  3. 03 / VerifyCheck the work before release

Where I use it

Marketing + brand

I use AI to organize research, compare messaging directions and develop channel concepts from a brief. I weigh the audience, portfolio fit and claims before choosing a direction.

Operations

I use agents to gather evidence, check it against requirements and prepare work for review. In my application workflow, the tracker records package readiness separately from submission.

AI training for teams

I design practice around a real brief, a worked example and a review checklist. The exercise is to give the agent enough context, evaluate what it returns and recognize when a person needs to step in.

Website + app development

I define how the experience should work, use coding agents to build in small changes and check the result in the browser. The design workflow map on this site is an example.
