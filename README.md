# Executive Site — V2 preview branch

A reversible, standalone working copy for John Cota’s executive website. The `v2-experience` branch contains the elevated V2 review preview; `main` preserves V1. No original evidence or synced project source was modified. See [V2_PREVIEW.md](V2_PREVIEW.md) for changes, evidence boundaries and remaining asset curation.

## Preview

Open `index.html` directly, or serve the folder:

```bash
python3 -m http.server 4173 --directory executive-site-v1
```

Then visit `http://127.0.0.1:4173`.
