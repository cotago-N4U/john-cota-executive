# Executive Site V1

A reversible, standalone working copy for John Cota’s executive website. No original evidence or synced project source was modified.

## Preview

Open `index.html` directly, or serve the folder:

```bash
python3 -m http.server 4173 --directory executive-site-v1
```

Then visit `http://127.0.0.1:4173`.
