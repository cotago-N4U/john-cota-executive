# Executive Site — V3 creative preview

A reversible, standalone working copy for John Cota’s executive website. The `v3-creative-experience` branch contains the scene-based V3 review preview; `v2-experience` preserves V2 and `main` preserves V1. No original evidence or synced project source was modified. See [V3_PREVIEW.md](V3_PREVIEW.md) for the experience, evidence boundaries and review notes.

## Preview

Open `index.html` directly, or serve the folder:

```bash
python3 -m http.server 4173 --directory executive-site-v1
```

Then visit `http://127.0.0.1:4173`.

## Before any V3 launch

- The verified LinkedIn destination is included. Reconcile the supplied résumé claims before adding a public download.
- Review the V3 preview before authorizing production publication. This branch has not been deployed.
- Run a final copy/legal/privacy review and verify email delivery.
- Add analytics only after choosing the owner/account and consent approach.
